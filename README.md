# ExchangeApp

Angular App Demo deployed to Google Cloud Run.

## Overview

This repository is a technical demonstration focused on automating the deployment of web applications to GCP Cloud Run using Terraform as the primary Infrastructure as Code (IaC) tool.

## Tech Stack

- Frontend: Angular
- Infrastructure as Code (IaC): Terraform
- Infrastructure: GCP Cloud Run
- CI/CD: GitHub Actions

## Deployment

This project is automatically deployed to Google Cloud Run upon every push, with all infrastructure resources managed and provisioned via Terraform.
